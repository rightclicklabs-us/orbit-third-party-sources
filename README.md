# Orbit Third-party Source Downloads

Optional source materials for the open-source engines included with **Orbit: File Converter & Editor**, published by Right Click Labs.

**You do not need these files to use Orbit.** Its working conversion engines are included with the app and work offline. This repository does not contain Orbit application code or the paid installer.

## Download

Open [Releases](https://github.com/rightclicklabs-us/orbit-third-party-sources/releases) and download `Orbit-Third-party-Sources-20261020.zip`. No GitHub account is required to download public release assets. The automatic GitHub "Source code" ZIP/TAR files contain this repository documentation, not the engine archives; choose the named asset instead.

The combined archive contains retained FFmpeg source materials and build records, LibreOffice 26.2.6.3 core and dictionaries, 7-Zip 26.05 sources, and libheif 1.23.6 / Kvazaar 2.3.2 sources with modifications, notices and HEIC build instructions. Component licenses apply individually. Runtime notices are also included with Orbit.

Archive size: **1,702,761,362 bytes** (approximately 1.70 GB / 1.59 GiB).

The archive includes `source-index.json` with checksums for its five component archives.
