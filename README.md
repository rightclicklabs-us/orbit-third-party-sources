# Orbit Third-party Source Downloads

Optional source materials for the open-source engines included with **Orbit: File Converter & Editor**, published by Right Click Labs.

**Normal customers only install Orbit.** Working conversion engines are included and run locally. This repository contains no Orbit application source or paid installer.

## Download the Current Collection

Use the [October 29, 2026 collection](https://github.com/rightclicklabs-us/orbit-third-party-sources/releases/tag/sources-2026-10-29) or the [source-download page](https://rightclicklabs.app/sources.html). Public downloads need no GitHub account.

- **Source Guide:** notices, modifications, component index, checksums, build and writable-copy replacement instructions.
- **Conversion Engine Sources:** frozen FFmpeg sources/recipes/dependencies, 7-Zip 26.05, modified libheif/Kvazaar sources.
- **Video Runtime Source Supplement:** matching GCC runtime sources, frozen toolchain configuration and patches. Use with Conversion Engine Sources.
- **Office Engine Sources:** LibreOffice 26.2.6.3 core, dictionaries, translations, and 115 verified external source inputs.
- **Image Engine Sources:** matching Magick.NET/Magick.Native/ImageMagick, build projects, and 42 pinned dependency source projects.

Choose these named release assets. GitHub’s automatic “Source code” ZIP/TAR files contain repository documentation only. Checksums and byte sizes are recorded on the release and website. Older collections remain as dated history.
